# Documentation

Ce dossier contient la documentation complémentaire du projet.

## Contenu prévu

- `user-guide.pdf` : guide d’utilisation du tableau de bord ;
- `methodology.md` : méthodologie détaillée ;
- `data-dictionary.pdf` : description des données et indicateurs.

## Objectif

La documentation permet à un utilisateur de comprendre :

- comment saisir les dépenses ;
- comment actualiser les analyses ;
- comment interpréter les indicateurs ;
- comment utiliser les graphiques et tableaux de synthèse.
